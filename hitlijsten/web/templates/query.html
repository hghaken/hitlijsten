Vrije query

Alleen SELECT. Wijzigen gaat via de bewerkschermen, want die leggen elke wijziging vast in het logboek — een typefout in een UPDATE is onherstelbaar. Er komen maximaal 500 rijen terug.

Voorbeelden
  • SELECT * FROM noteringen WHERE lijst='top40' AND jaar=1975 AND week=1 ORDER BY positie
  • SELECT artiest, COUNT(DISTINCT sleutel) n FROM noteringen WHERE lijst='top40' GROUP BY artiest ORDER BY n DESC LIMIT 20
  • SELECT jaar, COUNT(*) FROM noteringen WHERE positie=1 AND lijst='top40' GROUP BY jaar
  • SELECT * FROM wijzigingen ORDER BY id DESC

Tabellen: noteringen, opgehaald, aliases, niet_samenvoegen, bestaat_niet, onderscheidingen, correcties, wijzigingen.
